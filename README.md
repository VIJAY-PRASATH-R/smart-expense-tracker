# Smart Expense Tracker

This is my Web Development project – a simple web app that helps you track your daily expenses and manage notes in one place.

I built it using HTML, CSS, and JavaScript, and it stores data in your browser (LocalStorage), so everything stays even after refreshing the page.

---

## What it can do

### For Users
- Create your own account (register/login).
- Add your daily expenses with amount, category, date, and a small note.
- See a running list of all your expenses.
- View a monthly expense chart to understand where your money goes.
- Add personal notes and keep them safe.
- All your data stays private to you (stored in your browser).

### For Admin
- Special login just for the admin.
- Can see a list of all users.
- Check each user’s total expenses and notes.
- Reset user passwords if needed.
- Export user data (CSV file) or export all app data for analysis.
